# Data dictionary

All data is **synthetic** (generated by `model/simulator.py`). The sample in `synthetic/sample/` is
1 store × 7 days; run `python model/simulator.py` for the full 10 stores × 30 days set (git-ignored).

## Master data
**recipe_master.csv** — `sku, product_name, fryer_family (fries|chicken|empty = not fried), fried_g_per_unit,
stress_weight (relative oil stress per kg; fries = 1.0), basis (portion|estimate|grill), source_note`

**hist_orders_profile.csv** — `hour, orders_per_15min` (typical demand used by the simulator and the forecast)

## Synthetic tables
| File | Columns | Notes |
|---|---|---|
| pos_blocks.csv | store_id, block_start, n_orders | 15-min blocks, store open 07:00–24:00 |
| pos_items.csv | store_id, block_start, sku_id, quantity | units sold per SKU per block |
| tpm_readings.csv | measurement_id, store_id, vat_id, oil_batch_id, measurement_timestamp, tpm_pct, oil_temperature_c, device_id, measurement_validity_flag | ~5 readings/day, ±0.4 noise, ~2 % invalid |
| oil_events.csv | event_id, store_id, vat_id, oil_batch_id, action_timestamp, action_type (filter/top_up/full_change), fresh_oil_added_l, oil_removed_l, tpm_before | full change starts a new oil_batch_id |
| tpm_truth.csv | store_id, vat_id, oil_batch_id, block_start, true_tpm_end | hidden truth — evaluation only, never a model input |

Even-numbered stores change oil on a fixed 3-day schedule (early discards); odd-numbered stores change when a
reading reaches the illustrative 24 % limit.
